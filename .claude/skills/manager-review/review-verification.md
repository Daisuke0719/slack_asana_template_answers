# レビュー検証規則

## Severity

- Critical: 提出不可。重大な法令、契約、情報管理、セキュリティ、金額上の問題。
- Major: 完了条件、必須要件、主要ロジック、成果物間整合性に影響し、修正が必要。
- Minor: 表現、補足、軽微な明確化。主要結論は変わらない。

## 指摘の必須要素

- 対象箇所を特定できる。
- 成果物またはRFP上の根拠がある。
- 何が問題かと影響が分かれている。
- 改善案が実行可能である。
- 推測の場合は「要確認」と明記する。

## 除外する指摘

- タスク範囲外の好みだけの修正。
- 根拠のない業界慣行の断定。
- 同じ問題の重複指摘。
- 前回指摘が解消済みなのに未解消とする判定。
